Student Learning Outcome

  • Design, code, document, analyze, debug, and test advanced level Python programs that include Python modules for database, networking, graphics, and extensions.

Description

This course continues from CIS 41A, Python Programming, covering some topics in more detail, and adding more advanced topics. Object oriented programming, data structures, and functions as first class objects are covered extensively. New topics include data analysis, data visualization, graphical user interface programming, web access, database access, multi-threading and multiprocessing, network socket programming, operating system calls, timing and profiling, and Python extensions.

Course Objectives

  • Investigate modules, packages and processing sequences
  • Investigate functions as first class objects
  • Apply calls to OS services
  • Design GUI classes
  • Analyze and visualize data
  • Code for web access
  • Construct database access
  • Design multithreading code
  • Design multiprocessing code
  • Write network socket code
  • Utilize programmer tools

Grades

Each assignment is rated on a scale from 0 to 5 based on this criteria:

A. Functionality

  • Correctness: The program produces the correct output for a variety of input cases, including edge cases.
  • Completeness: The program implements all required features and meets the specified requirements.
  • Reliability: The program is stable and handles errors gracefully without crashing.

B. Performance

  • Efficiency: The program performs well in terms of speed and resource usage (CPU, memory, disk, etc.).
  • Scalability: The program handles increasing amounts of data or users without significant performance degradation.
  • Responsiveness: The program is responsive to user inputs and provides timely feedback.

C. Usability

  • User Interface (UI): The user interface is intuitive, visually appealing, and easy to navigate.
  • User Experience (UX): The program offers a positive experience, with smooth interactions and easy-to-understand instructions.

D. Maintainability

  • Code Quality: The code is clean, well-organized, and readable with meaningful variable/function names.
  • Modularity: The program is divided into well-defined modules or components that can be developed and tested independently.
  • Testability: The program is designed to facilitate testing, with appropriate use of unit tests.

Students often come into this course with the expectation of getting high scores on their assignments because their programs produce the correct output. But this expectation ignores any concept of coding quality. Assignments that meet the output requirements but demonstrate low coding quality will receive a low rating.

Code Rating:

  • 0 - Not working:
    • The program doesn't compile.
    • The expected output isn't correct.
    • There are runtime errors.
    • Coding style is elementary or below sub-standard.
  • 1 - Marginally Working:
    • Some functionality is present, but the program has major issues.
    • Many features are incomplete or incorrect.
    • The code quality is low with numerous flaws in logic and structure.
    • Coding style is slightly above sub-standard.
  • 2 - Below Average:
    • The program works but has several significant bugs or design flaws.
    • Some features are implemented correctly, but others are incomplete or incorrect.
    • The code is subpar, with a fair number of errors and inconsistencies.
    • Coding style is below average.
  • 3 - Meets Requirements:
    • The program meets the assignment requirements and is mostly functional.
    • Minor bugs or inefficiencies may be present, but core features work as intended.
    • The code quality is acceptable, with some room for improvement.
    • Coding style is average, indicating average coding skills.
  • 4 - Good:
    • The program is complete and works as expected with few minor issues.
    • Demonstrates a good understanding of the assignment requirements.
    • The code is well-written, with minimal errors and good structure.
    • Coding style is above average, indicating good programming skills.
  • 5 - Excellent:
    • The program exceeds the assignment requirements and is fully functional with no issues.
    • Demonstrates a high level of understanding and application of concepts.
    • The code is well-organized, efficient, and error-free, showing superior quality and creativity.
    • Coding style far exceeds the average coding quality.

Late Assignments

To ensure fairness and encourage timely submission, assignments turned in past the deadline will incur a penalty on the overall rating. If you turn in an assignment late, please put a note at the top of your late submission explaining why it was turned in late, rather than sending an email requesting an extension to the assignment. Emails requesting a late extension will be ignored. The reduction will be applied as follows, and includes the difficulty for assignment:

Days Late Point Deduction
1 to 5 days late 1-point deduction * difficulty
6 to 10 days late 2-point deduction * difficulty
11 to 14 days late 3-point deduction * difficulty
>15 days late 0 points for assignment

Assignment Notes

Static functions will receive a 1 point reduction in rating, because they are not first-class functions. If you must submit a function as static, declare the reason where the static function is implemented in your code.

Academic Integrity

In this course, we highly value academic honesty and the importance of original work. It's important to avoid actions that constitute cheating, such as copying code or work from others, using unauthorized materials during exams, and submitting work that isn't your own. Remember, copying from the internet, AI tools like ChatGPT, or from other students will result in a grade of 0 for that assignment. Additionally, any previously submitted work will be reviewed for potential copying. Repeated instances of copying could lead to failing the course.
